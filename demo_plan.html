1. Intro

0:00-0:15
Show the project folder in VS Code.
“This is my AI Browser Extension for Phishing Detection. The project uses a browser extension, a Flask backend, and a machine learning model to detect suspicious URLs in real time.”

2. Project Structure

0:15-0:45
Point to these folders: dataset, backend, model, extension, and tests.
“The project is divided into main parts. The dataset folder stores phishing and legitimate URL data. The backend folder contains the Flask API, feature extraction, and model training code. The model folder stores the trained model. The extension folder contains the Chrome extension files, and tests contains automated tests.”

3. Feature Extraction

0:45-1:15
Open backend/features.py.
“This file extracts features from URLs. Instead of sending raw URLs directly to the model, the system converts them into numeric features such as URL length, number of dots, hyphens, digits, HTTPS usage, IP address detection, suspicious keywords, suspicious TLDs, entropy, path depth, and query length.”
Scroll slightly. Do not read every feature line.

4. Model Training

1:15-1:40
Open backend/train_model.py, then briefly show model/phishing_model.pkl.
“This file trains the machine learning model. It loads the dataset, cleans it, extracts URL features, trains multiple models like Logistic Regression, Decision Tree, Random Forest, and Naive Bayes, then selects the best model based on phishing recall and F1-score. The final selected model is saved as a .pkl file.”

5. Flask Backend

1:40-2:05
Open backend/app.py.
“This is the Flask backend. The extension sends the current URL to the /predict endpoint. The backend first checks trusted legitimate domains, then extracts features and sends them to the trained model. It returns a prediction and risk score.”
“There is also a feedback endpoint called /mark-legitimate. If a website is wrongly marked suspicious, the user can mark it as legitimate.”

6. Extension Files

2:05-2:25
Open extension/manifest.json, extension/background.js, and extension/popup.js.
“The manifest defines the Chrome extension permissions, popup, background script, and content script. The background script scans tabs, calls the Flask backend, stores results, and sends warnings to the page. The popup shows the current URL, risk score, status, and actions like rescan or mark as legit.”

7. Run the Extension

2:25-2:45
Show PowerShell with the Flask backend running.

“To run the project, first start the Flask backend. Then open Chrome extensions, enable Developer mode, click Load unpacked, and select the extension folder. Since mine is already loaded, I only need to reload it after code changes.”
